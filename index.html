JSON কী?

JSON (JavaScript Object Notation) হলো ডেটা আদান-প্রদানের একটি সহজ টেক্সট-ভিত্তিক ফরম্যাট। ওয়েবসাইট, মোবাইল অ্যাপ ও সার্ভারের মধ্যে তথ্য পাঠাতে প্রায় সব API এখন JSON ব্যবহার করে। এটি মানুষ পড়তে পারে, আবার কম্পিউটারও সহজে বুঝতে পারে।

JSON-এ ছয় ধরনের মান থাকে: অবজেক্ট { }, অ্যারে [ ], স্ট্রিং "লেখা", সংখ্যা 42, বুলিয়ান true/false এবং null।

JSON বন্ধু দিয়ে যা করতে পারবেন

  • ফরম্যাট: এক লাইনের জটিল JSON সুন্দর করে সাজানো, পড়ার উপযোগী রূপে।
  • যাচাই: ভুল থাকলে কোন লাইন ও কলামে ভুল, তা বাংলায় দেখায় এবং কার্সর সেখানে নিয়ে যায়।
  • ভুল ঠিক করুন: কমেন্ট, শেষের বাড়তি কমা, সিঙ্গেল কোট, কোটবিহীন কী ও Python-এর True/False/None স্বয়ংক্রিয়ভাবে ঠিক করে।
  • ট্রি ভিউ: বড় JSON ভাঁজ করে দেখা, খোঁজা এবং যেকোনো মানের পাথ (যেমন $.users[0].name) কপি করা।
  • রূপান্তর: JSON থেকে CSV (এক্সেলে বাংলা ঠিকমতো দেখায়), YAML ও XML।

গোপনীয়তা

সব কাজ আপনার ব্রাউজারের ভেতরেই হয়। আপনার JSON কোনো সার্ভারে আপলোড বা সংরক্ষণ করা হয় না। বিস্তারিত দেখুন গোপনীয়তা নীতি-তে।

প্রশ্নোত্তর

আমার ডেটা কি নিরাপদ?

হ্যাঁ। প্রসেসিং সম্পূর্ণ আপনার ডিভাইসে হয়। শেষ ইনপুটটি শুধু আপনার নিজের ব্রাউজারে সংরক্ষিত থাকে, যাতে পেজ রিফ্রেশ করলে হারিয়ে না যায়।

“Unexpected token” ভুল কেন আসে?

সাধারণত শেষে বাড়তি কমা, সিঙ্গেল কোট ( ' ) ব্যবহার, বা কী-এর চারপাশে কোট না থাকার কারণে। “ভুল ঠিক করুন” বোতাম চাপলে বেশিরভাগ ক্ষেত্রে এগুলো ঠিক হয়ে যায়।

CSV এক্সেলে খুললে বাংলা ভেঙে যায় কেন?

JSON বন্ধুর ডাউনলোড করা CSV-তে UTF-8 BOM যোগ করা থাকে, তাই এক্সেলে বাংলা ঠিকমতো দেখায়।

কত বড় ফাইল খোলা যাবে?

আপনার ডিভাইসের মেমোরির ওপর নির্ভর করে; সাধারণত কয়েক MB পর্যন্ত স্বাচ্ছন্দ্যে কাজ করে।
