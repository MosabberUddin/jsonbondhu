CSV and JSON in a nutshell

CSV (comma-separated values) is a plain-text table: one record per line, fields separated by a delimiter. Every spreadsheet can open and save it, which makes it the everyday format for exports, bank statements and mailing lists. JSON describes structured data — objects, lists, numbers, true/false and null — and is what web APIs, JavaScript apps and most databases speak.

Convert CSV to JSON when you want to feed a spreadsheet into code, seed a database or mock an API. Convert JSON to CSV when a colleague needs to open API data in Excel or Google Sheets, or you want a quick sortable table of a response.

Delimiters and Excel quirks

  • In many European locales Excel saves CSV with semicolons, because the comma is the decimal separator there. The converter detects comma, semicolon, tab and pipe automatically; you can also pick one yourself.
  • Excel reads CSV in the system code page unless the file starts with a byte-order mark. Our CSV downloads include a UTF-8 BOM so Bangla and other scripts show correctly.
  • Spreadsheets like to strip leading zeros and turn long numbers into scientific notation. Type detection here only converts a value when its JSON form is exactly the same text, so 00123, 01712345678 or 1.50 stay strings.
  • Nested JSON objects become columns such as address.city; tick “Rebuild nested objects” to turn them back. Lists are stored as JSON text inside a cell.

FAQ

Is my data uploaded?

No. Parsing and conversion run entirely in your browser; nothing is sent to a server.

What happens to rows with too many or too few fields?

They are kept. Missing cells become empty (or null), extra cells get columns named col4, col5… and the status bar lists the affected line numbers so you can check them.

What is the formula protection option?

A cell such as =HYPERLINK(…) may run as a formula when the CSV is opened in a spreadsheet — a known attack called CSV injection. The option adds an apostrophe in front of text that starts with = + - or @. It is off by default because it changes the data.

How big a file can it handle?

Files of several megabytes usually convert in about a second on a normal laptop. The preview shows the first 50 rows; the output always contains everything.

সংক্ষেপে CSV আর JSON

CSV (কমা দিয়ে আলাদা করা মান) হলো সাধারণ টেক্সটে লেখা একটি টেবিল: প্রতি লাইনে একটি রেকর্ড, আর ঘরগুলো একটি ডিলিমিটার দিয়ে আলাদা। যেকোনো স্প্রেডশিট এটি খুলতে ও সেভ করতে পারে, তাই এক্সপোর্ট, ব্যাংক স্টেটমেন্ট বা ঠিকানার তালিকায় CSV-ই সবচেয়ে বেশি চলে। JSON গোছানো ডেটা প্রকাশ করে — অবজেক্ট, লিস্ট, সংখ্যা, true/false আর null — এবং ওয়েব API, জাভাস্ক্রিপ্ট অ্যাপ ও বেশিরভাগ ডেটাবেস এই ভাষাতেই কথা বলে।

স্প্রেডশিটের ডেটা কোডে ব্যবহার করতে, ডেটাবেসে প্রাথমিক ডেটা ঢোকাতে বা নকল API বানাতে CSV থেকে JSON করুন। আর API-র ডেটা কাউকে Excel বা Google Sheets-এ খুলে দেখাতে, কিংবা একটি রেসপন্স টেবিল আকারে সাজিয়ে দেখতে JSON থেকে CSV করুন।

ডিলিমিটার ও Excel-এর ঝামেলা

  • অনেক ইউরোপীয় সেটিংসে দশমিকের জন্য কমা ব্যবহার হয়, তাই সেখানে Excel CSV সেভ করে সেমিকোলন দিয়ে। এই কনভার্টার কমা, সেমিকোলন, ট্যাব ও পাইপ নিজেই চিনে নেয়; চাইলে আপনি নিজেও বেছে দিতে পারেন।
  • ফাইলের শুরুতে বাইট-অর্ডার মার্ক (BOM) না থাকলে Excel CSV-কে পুরোনো এনকোডিংয়ে পড়ে, ফলে বাংলা ভেঙে যায়। আমাদের ডাউনলোড করা CSV-তে UTF-8 BOM থাকে, তাই বাংলা ঠিকঠাক দেখা যায়।
  • স্প্রেডশিট প্রায়ই শুরুর শূন্য মুছে ফেলে বা লম্বা সংখ্যাকে বৈজ্ঞানিক রূপে দেখায়। এখানে টাইপ শনাক্তকরণ কেবল তখনই মান বদলায় যখন JSON রূপটি হুবহু একই টেক্সট হয় — তাই 00123, 01712345678 বা 1.50 স্ট্রিং হিসেবেই থাকে।
  • নেস্টেড JSON অবজেক্ট address.city-এর মতো কলামে পরিণত হয়; আবার আগের রূপে ফেরাতে “নেস্টেড অবজেক্ট আবার তৈরি করুন” চালু করুন। লিস্টগুলো একটি ঘরের ভেতরে JSON টেক্সট হিসেবে থাকে।

প্রশ্নোত্তর

আমার ডেটা কি আপলোড হয়?

না। পার্সিং ও রূপান্তর পুরোটাই আপনার ব্রাউজারে হয়; কোনো সার্ভারে কিছু পাঠানো হয় না।

কোনো সারিতে ঘর বেশি বা কম থাকলে কী হয়?

সারিটি বাদ পড়ে না। না-থাকা ঘর ফাঁকা (বা null) হয়, বাড়তি ঘরগুলো col4, col5… নামের কলামে যায়, আর স্ট্যাটাস বারে কোন কোন লাইনে সমস্যা তা দেখানো হয় যাতে আপনি মিলিয়ে নিতে পারেন।

ফর্মুলা থেকে সুরক্ষা অপশনটি কী?

=HYPERLINK(…)-এর মতো কোনো ঘর স্প্রেডশিটে খুললে ফর্মুলা হিসেবে চলে যেতে পারে — এটিকে CSV ইনজেকশন বলে। অপশনটি = + - বা @ দিয়ে শুরু হওয়া টেক্সটের আগে একটি অ্যাপোস্ট্রফি (') যোগ করে। এতে ডেটা বদলে যায়, তাই শুরুতে এটি বন্ধ থাকে।

কত বড় ফাইল চালানো যায়?

সাধারণ ল্যাপটপে কয়েক মেগাবাইটের ফাইল সাধারণত এক সেকেন্ডের মতো সময়ে রূপান্তর হয়। প্রিভিউতে প্রথম ৫০টি সারি দেখায়, তবে আউটপুটে সবকিছুই থাকে।
