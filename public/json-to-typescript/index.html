Turn a JSON sample into TypeScript types

Paste a JSON response and get matching interface or type declarations you can drop into your code. Every nested object becomes its own named type, named from its key in PascalCase (user_address becomes UserAddress). Objects with the same shape share one type, and a name that is already taken gets a number suffix.

How the types are inferred

  • Arrays of objects are merged into one type. With “Optional keys when merging” on, a key missing from some elements becomes key?: T. Turn it off to keep differently shaped objects as separate union members.
  • Mixed arrays become unions such as (string | number)[], and an empty array becomes unknown[].
  • null is kept: a value that is sometimes null becomes string | null.
  • Keys that are not valid identifiers, like my-key, are quoted. Unicode keys such as Bangla names stay unquoted because TypeScript accepts them.

Know the limits

A single sample cannot tell the tool everything. A field that is always a string in your sample might be a number elsewhere, and a field present in every sample element might still be optional in the API. Review the output before you rely on it.

Everything runs in your browser. Your JSON is not uploaded.

JSON নমুনা থেকে TypeScript টাইপ তৈরি করুন

একটি JSON রেসপন্স পেস্ট করলেই মানানসই interface বা type পেয়ে যাবেন, যা সরাসরি কোডে বসানো যায়। প্রতিটি নেস্টেড অবজেক্ট আলাদা নামের টাইপ হয়, নামটি আসে কী থেকে PascalCase-এ (user_address হয় UserAddress)। একই গঠনের অবজেক্ট একটি টাইপ ভাগ করে নেয়, আর নাম আগেই নেওয়া থাকলে শেষে সংখ্যা যোগ হয়।

টাইপ কীভাবে অনুমান করা হয়

  • অবজেক্টের অ্যারে মিলিয়ে একটি টাইপ হয়। “মেলানোর সময় ঐচ্ছিক কী” চালু থাকলে কিছু এলিমেন্টে না থাকা কী হয় key?: T। বন্ধ করলে ভিন্ন গঠনের অবজেক্টগুলো আলাদা ইউনিয়ন সদস্য থাকে।
  • মিশ্র অ্যারে হয় ইউনিয়ন, যেমন (string | number)[]; ফাঁকা অ্যারে হয় unknown[]।
  • null রাখা হয়: যে মান কখনো null হয়, সেটি হয় string | null।
  • বৈধ আইডেন্টিফায়ার নয় এমন কী, যেমন my-key, কোটের ভেতরে লেখা হয়। বাংলা নামের মতো ইউনিকোড কী কোট ছাড়াই থাকে, কারণ TypeScript তা মানে।

সীমাবদ্ধতা

একটি নমুনা থেকে সবকিছু জানা যায় না। নমুনায় সবসময় স্ট্রিং থাকা ফিল্ড অন্য জায়গায় সংখ্যা হতে পারে, আর নমুনার সব এলিমেন্টে থাকা ফিল্ডও API-তে ঐচ্ছিক হতে পারে। ব্যবহারের আগে আউটপুট মিলিয়ে দেখুন।

সবকিছু আপনার ব্রাউজারেই চলে। আপনার JSON কোথাও আপলোড হয় না।
