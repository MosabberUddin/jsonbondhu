What is JSON?

JSON (JavaScript Object Notation) is a simple, text-based format for exchanging data. Almost every API that connects websites, mobile apps and servers uses JSON today. People can read it, and computers can parse it easily.

JSON has six kinds of values: object { }, array [ ], string "text", number 42, boolean true/false and null.

What you can do with JSON Bondhu

  • Format: turn a dense one-line JSON into neatly indented, readable text.
  • Validate: see exactly which line and column has an error, with the cursor moved there.
  • Fix errors: automatically repairs comments, trailing commas, single quotes, unquoted keys and Python's True/False/None.
  • Tree view: fold large JSON, search it, and copy the path to any value (e.g. $.users[0].name).
  • Convert: JSON to CSV (opens correctly in Excel, including Bangla text), YAML and XML.

Privacy

Everything happens inside your browser. Your JSON is never uploaded to or stored on any server. See the privacy policy for details.

JSON কী?

JSON (JavaScript Object Notation) হলো ডেটা আদান-প্রদানের একটি সহজ টেক্সট-ভিত্তিক ফরম্যাট। ওয়েবসাইট, মোবাইল অ্যাপ ও সার্ভারের মধ্যে তথ্য পাঠাতে প্রায় সব API এখন JSON ব্যবহার করে। এটি মানুষ পড়তে পারে, আবার কম্পিউটারও সহজে বুঝতে পারে।

JSON-এ ছয় ধরনের মান থাকে: অবজেক্ট { }, অ্যারে [ ], স্ট্রিং "লেখা", সংখ্যা 42, বুলিয়ান true/false এবং null।

JSON বন্ধু দিয়ে যা করতে পারবেন

  • ফরম্যাট: এক লাইনের জটিল JSON সুন্দর করে সাজানো, পড়ার উপযোগী রূপে।
  • যাচাই: ভুল থাকলে কোন লাইন ও কলামে ভুল, তা বাংলায় দেখায় এবং কার্সর সেখানে নিয়ে যায়।
  • ভুল ঠিক করুন: কমেন্ট, শেষের বাড়তি কমা, সিঙ্গেল কোট, কোটবিহীন কী ও Python-এর True/False/None স্বয়ংক্রিয়ভাবে ঠিক করে।
  • ট্রি ভিউ: বড় JSON ভাঁজ করে দেখা, খোঁজা এবং যেকোনো মানের পাথ (যেমন $.users[0].name) কপি করা।
  • রূপান্তর: JSON থেকে CSV (এক্সেলে বাংলা ঠিকমতো দেখায়), YAML ও XML।

গোপনীয়তা

সব কাজ আপনার ব্রাউজারের ভেতরেই হয়। আপনার JSON কোনো সার্ভারে আপলোড বা সংরক্ষণ করা হয় না। বিস্তারিত দেখুন গোপনীয়তা নীতি-তে।

FAQ

Is my data safe?

Yes. All processing happens on your device. Only your last input is kept, in your own browser, so it isn't lost if you refresh the page.

Why do I get “Unexpected token” errors?

Usually because of a trailing comma, single quotes ( ' ), or keys without quotes. Pressing “Fix errors” repairs most of these automatically.

Why does Bangla text break when I open a CSV in Excel?

CSV files downloaded from JSON Bondhu include a UTF-8 BOM, so Excel shows Bangla (and other non-English text) correctly.

How large a file can I open?

It depends on your device's memory; files of a few MB usually work comfortably.

প্রশ্নোত্তর

আমার ডেটা কি নিরাপদ?

হ্যাঁ। প্রসেসিং সম্পূর্ণ আপনার ডিভাইসে হয়। শেষ ইনপুটটি শুধু আপনার নিজের ব্রাউজারে সংরক্ষিত থাকে, যাতে পেজ রিফ্রেশ করলে হারিয়ে না যায়।

“Unexpected token” ভুল কেন আসে?

সাধারণত শেষে বাড়তি কমা, সিঙ্গেল কোট ( ' ) ব্যবহার, বা কী-এর চারপাশে কোট না থাকার কারণে। “ভুল ঠিক করুন” বোতাম চাপলে বেশিরভাগ ক্ষেত্রে এগুলো ঠিক হয়ে যায়।

CSV এক্সেলে খুললে বাংলা ভেঙে যায় কেন?

JSON বন্ধুর ডাউনলোড করা CSV-তে UTF-8 BOM যোগ করা থাকে, তাই এক্সেলে বাংলা ঠিকমতো দেখায়।

কত বড় ফাইল খোলা যাবে?

আপনার ডিভাইসের মেমোরির ওপর নির্ভর করে; সাধারণত কয়েক MB পর্যন্ত স্বাচ্ছন্দ্যে কাজ করে।
