      Cheat sheet
      

        
.Any character except a line break

        
\d \w \sDigit, word character, whitespace (capitals mean the opposite)

        
[abc] [^abc] [a-z]Character set, negated set, range

        
^ $ \bStart, end, word boundary

        
* + ? {2,4}Repeat: 0 or more, 1 or more, optional, a range (add ? for lazy)

        
(…) (?:…) (?<n>…)Capturing group, non-capturing group, named group

        
a|bEither a or b

        
(?=…) (?!…) (?<=…) (?<!…)Lookahead and lookbehind

        
$1 $<n> $& $$In the replacement: group, named group, whole match, a literal $

How to test a regular expression

      
Type a pattern, tick the flags you need and paste some text. Matches are highlighted as you type, and the list below shows each match with its position, numbered groups and named groups. Use the replace box to preview a substitution with $1 or $<name>.

      
Which regex engine is this?

      
This tool uses the JavaScript (ECMAScript) RegExp engine built into your browser. Syntax and behaviour match what you get in JavaScript and Node.js, but can differ from PCRE, Python, Java or PHP (for example in lookbehind, named group syntax and flags).

      
Limits that keep the page responsive

      
    
        
  • At most 1000 matches are listed and only the first 50,000 characters of text are searched.
    • 
        
  • Empty matches are handled safely, so patterns like x* never loop forever.
    • 
        
  • Nested quantifiers such as (a+)+ can take exponentially long on some inputs, and a browser cannot interrupt a running regex. The page warns you about this shape, but if a pattern still hangs the tab, reload it.
    • 
      

      
Is my text sent anywhere?

      
No. Everything runs in your browser and nothing is uploaded.

    

    

      
রেগুলার এক্সপ্রেশন কীভাবে পরীক্ষা করবেন

      
একটি প্যাটার্ন লিখুন, প্রয়োজনীয় ফ্ল্যাগ বেছে নিন এবং টেক্সট পেস্ট করুন। লেখার সাথে সাথেই মিলগুলো হাইলাইট হয়, আর নিচের তালিকায় প্রতিটি মিলের অবস্থান, নম্বরযুক্ত গ্রুপ ও নামযুক্ত গ্রুপ দেখানো হয়। রিপ্লেস বক্সে $1 বা $<name> লিখে বদলের ফলাফল আগেই দেখে নিতে পারবেন।

      
এটি কোন রেজেক্স ইঞ্জিন?

      
এখানে আপনার ব্রাউজারে থাকা JavaScript (ECMAScript) RegExp ইঞ্জিন ব্যবহার করা হয়। JavaScript ও Node.js-এ যেমন চলে, এখানেও ঠিক তেমন চলবে; তবে PCRE, Python, Java বা PHP-এর সাথে কিছু পার্থক্য থাকতে পারে (যেমন লুকবিহাইন্ড, নামযুক্ত গ্রুপের সিনট্যাক্স ও ফ্ল্যাগ)।

      
পেজ সচল রাখার সীমা

      
    
        
  • সর্বোচ্চ ১০০০টি মিল দেখানো হয় এবং টেক্সটের প্রথম ৫০,০০০ অক্ষর খোঁজা হয়।
    • 
        
  • ফাঁকা মিল নিরাপদে সামলানো হয়, তাই x*-এর মতো প্যাটার্ন কখনো অসীম লুপে আটকায় না।
    • 
        
  • (a+)+-এর মতো নেস্টেড কোয়ান্টিফায়ার কিছু ইনপুটে অস্বাভাবিক সময় নিতে পারে, আর চলমান রেজেক্স ব্রাউজার থামাতে পারে না। এমন গঠন দেখলে পেজ সতর্ক করে, তবু ট্যাব আটকে গেলে রিলোড করুন।
    • 
      

      
আমার টেক্সট কি কোথাও পাঠানো হয়?
